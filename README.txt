SHOPKART FULL STACK

Project folders:
- shopkart-angular: Angular frontend
- shopkart-backend: Spring Boot + MySQL backend, product APIs and working register/login APIs

Read shopkart-backend/README.txt for full setup. Configure MySQL password, start Spring Boot first, then run npm install and npm start inside shopkart-angular.

Live Razorpay payment requires your own keys and server-side verification; no secret credentials are included. This is a development starter, not production hardened.
